# Daily Robotics Intelligence — V1 format

## 今日最值得看

Select 5–10 events with the highest combined hotness and robotics relevance.

For each item show:
- title
- hot score
- robotics relevance
- SoC relevance
- source tier
- 2–3 sentence summary
- one-line “为什么值得看”

## 今日三条趋势

Aggregate individual events into 1–3 emerging trends. A trend should require multiple independent events or a strong first-party signal.

For each trend:
- trend name
- evidence
- current stage: signal / forming / established
- robotics implication
- SoC implication

## SoC Radar

Summarize only hardware-relevant signals:
- TOPS / precision
- CPU/GPU/NPU/MCU
- memory capacity / bandwidth
- camera / ISP / sensor I/O
- power / thermal
- compiler / runtime / operator support

## Company Watch

Track notable moves from:
NVIDIA, Qualcomm, Arm, D-Robotics, Horizon Robotics, Rockchip, Ambarella, Axera, Tesla, Figure AI, Unitree, Boston Dynamics, 1X, Apptronik, Agility Robotics, Physical Intelligence, Skild AI, Google DeepMind.

## 商业机会与风险

Only include actionable signals:
- new design-win opportunity
- customer segment change
- competitor movement
- supply-chain change
- pricing pressure
- ecosystem partnership
- mass-production signal

## 继续观察

End with 3–5 concrete things to monitor over the next several days.
